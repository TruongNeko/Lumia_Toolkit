# 📱 Lumia Toolkit (Thor2 Wrapper)

![Windows](https://img.shields.io/badge/OS-Windows-blue)
![Shell](https://img.shields.io/badge/Script-Batch-green)
![Device](https://img.shields.io/badge/Support-Lumia%20%2F%20Windows%20Phone-orange)

A lightweight CLI batch tool wrapper powered by **Thor2** (from Windows Device Recovery Tool). Designed for Lumia users and modders to easily check device information, manage reboot states, and simplify flashing procedures.

---

## ✨ Features

* 🔍 **Connection Check:** Auto-detect connected Nokia/Microsoft Lumia devices.
* 📋 **Deep Info Extraction:** Read IMEI, Partition Layout, Root Key Hash, and more in Flash Mode.
* 🔄 **Device Control:** Soft reboot and mode-switching commands out of the box.
* 🎨 **Enhanced UI:** ANSI color support for clean readability.
* ⚡ **Stability Fixes:** Crash-free key listener handling with zero system beeps.

---
